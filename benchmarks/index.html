Methodology
Test corpus: 2,400 enterprise voice commands across 4 intent layers, sourced from publicly available customer service and enterprise workflow datasets. No proprietary data used.

Latency: Measured as time from input submission to structured JSON output, averaged over 100 runs per query type, excluding network overhead. ConceptNet runs locally; OpenAI/Claude times are API round-trip from London, UK.

Cost: Based on published API pricing as of July 2026. OpenAI GPT-4o at $0.005/1K tokens input, $0.015/1K output. Claude Sonnet at $0.003/$0.015. ConceptNet token-free architecture costs measured against equivalent cloud compute.

Accuracy: Human-labelled ground truth on intent layer classification. Single-label classification task per command.

Reproducibility: All test scripts and datasets available at github.com/wushu75/ConceptNet/benchmarks.
